# 文档入口

当前正式版是 v1.3.0。第一次使用从[项目首页](../README.md)开始；下表按要完成的事情选择指南。

| 你要做什么 | 入口 |
|---|---|
| 下载正确安装包、选择模式、判断成功 | [首页](../README.md) |
| 安装、升级、改密码、迁移、暂停和卸载 | [使用指南](USAGE.md) |
| 安装或联网异常、安全软件告警、反馈问题 | [故障排查](TROUBLESHOOTING.md) |
| 源码运行、测试、构建和跨平台开发 | [开发指南](DEVELOPMENT.md)、[三层结构](ARCHITECTURE.md) |
| 提交 PR、维护版本、校验及发布包来源 | [贡献流程](../CONTRIBUTING.md)、[维护与发布](MAINTENANCE.md) |
| v1.3.0 已发布内容和验证边界 | [版本说明](releases/v1.3.0.md)、[最终验收](releases/v1.3.0-acceptance.md) |
| 故障、建议与敏感问题反馈 | [Issue 模板](https://github.com/LeeAstra/autologin-sias/issues/new/choose)、[安全反馈说明](../SECURITY.md) |
| 查阅旧版、实验和历史测量 | [历史与实验索引](history/README.md) |

当前操作只在使用和故障指南中详细说明；旧清单、候选说明和旧版命令属于历史资料，不用于直接配置 v1.3.0。
