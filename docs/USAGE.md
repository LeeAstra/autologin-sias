# 使用指南：安装与日常维护

适用于已发布的 v1.3.0，面向使用完整安装器的 Windows 用户。首次下载见[首页](../README.md)；出现错误时转到[故障排查](TROUBLESHOOTING.md)。

## 安装前准备

先连接 UESTC，准备校园网账号密码，并使用自己的 Windows 管理员账户。安装器会显示 Windows 管理员权限提示（UAC）；不要改用另一个管理员账户提权。安装包未签名，应从[正式 Release](https://github.com/LeeAstra/autologin-sias/releases/tag/v1.3.0)取得并按需[校验 SHA256](MAINTENANCE.md#校验下载文件)。

安装和重新安装都会提交凭据验证；已经能上网也不能替代密码验证。升级时还会短暂停止当前维护、替换程序和配置、更新任务。先关闭其他安装窗口，保存正在进行的工作。

## 安装目录和凭据

1. 打开 `AutoLogin_SIAS_Installer.exe` 并允许 UAC，在“安装目录”提示处选择位置。直接回车使用 `%LOCALAPPDATA%\AutoLogin_SIAS`。
2. 自选目录请输入完整的本地绝对路径，例如 `C:\AutoLogin_SIAS`；不要输入相对路径或使用启用 EFS 文件加密的目录。**升级时默认目录仍是上述默认值，沿用旧位置必须输入旧任务实际目录。**
3. 根据[首页模式表](../README.md#选择哪种模式)选择 `1` 或 `2`，默认 `2`。
4. 如果看到“检测到旧配置，保留账号密码？[Y/n]”，回车复用，输入 `n` 重新输入。安装器优先读取目标目录已有配置，否则读取可识别旧任务所在目录的配置，不扫描整台电脑。
5. 核对“将安装至 …，更新 AutoLogin_SIAS 任务为 … 模式”，在“确认安装？[Y/n]”中回车。输入 `n` 会取消。
6. 等待凭据验证、任务注册及启动请求。看到“部署完成”后关闭窗口，再按[运行核验](TROUBLESHOOTING.md#确认任务和本轮运行)确认。

实际安装目录通常包含 `AutoLogin_SIAS_Headless.exe`、`Install-AutoLoginTask.ps1`、`.env`，运行后产生 `auto_login_headless.log` 及轮转日志。下载的安装器和安装目录是两个位置，删除下载文件不会卸载程序。

找不到目录时，按 `Win + R` 输入 `taskschd.msc`，打开 `AutoLogin_SIAS` 的“属性 → 操作”，查看后台 EXE 所在目录。不要根据旧文档或安装器默认值猜测当前路径。

## 运行条件与触发方式

两种模式的默认值见[首页](../README.md#选择哪种模式)。窗口使用电脑本地时间，02:55 包含在窗口内，03:15 不包含。提交前重新确认 UESTC 和时间；已开始的请求可以完成，窗口结束后下一轮退出，所以退出时间可能略晚于 03:15。

| 条件 | v1.3.0 完整安装器配置的行为 |
|---|---|
| UESTC 连接事件 | 事件触发约延迟 30 秒请求启动；系统负载可能增加延迟 |
| 开机、当前账户登录 | 约延迟 30 秒请求启动 |
| 夜间模式每日 02:55 | 定时请求启动，在窗口内检测 |
| 持续模式 | 没有固定每日启动时间；正在运行时循环检测 |
| 已有实例运行，又被触发 | 忽略新的启动请求，避免重复维护 |
| 明确离开 UESTC | 维护退出；不能核实 Wi-Fi 时先等待，不盲目认证 |
| 已认证 / 未知认证状态 | 已认证只检测；未知等待下一轮 |
| 电脑睡眠 | 无法检测；不自动唤醒，恢复后的实际运行需结合任务条件核验 |

安装器更新本应用的网络、开机、登录及时间触发器、动作参数和执行时限，保留旧任务电源条件。不能将“升级”理解为旧定时时刻原样保留。不支持的旧任务会在停止任务和替换文件前拒绝升级。

轮询间隔之外还有网络操作时间；实际认证提交后至少等待 15 秒才允许重试。不要把“五秒检测”理解为恢复时间承诺，也不要用单晚观测推断每晚登出次数。

## 升级、切换模式或更换凭据

这些操作均通过完整安装器完成，会更新同名计划任务。仅替换后台 EXE 不会完成这些配置变更。

1. 在任务“操作”中记录当前目录和模式，从 Release 下载需要的完整安装器。
2. 运行安装器，**输入当前目录**，选择希望使用的模式；不要凭回车假定沿用旧目录。
3. 保留凭据则在旧配置询问处回车；换账号或密码则输入 `n`，再输入新值。
4. 核对并确认安装，等待完成后检查任务路径、参数和本轮运行。

重新选择模式会显式更新对应触发器；升级或改密码时仍需选择想保留的模式。自动备份和失败恢复见[安装及恢复失败](TROUBLESHOOTING.md#安装及恢复失败)。

## 迁移目录及处理旧文件

迁移会短暂停止旧维护，切换任务执行路径并验证凭据；本版**不自动删除旧目录文件**。

1. 先记录任务当前路径，再运行安装器，输入新目录，选择模式和凭据。
2. 安装后打开任务“属性 → 操作”，确认执行路径已指向新目录。
3. 根据本轮日志确认新目录程序实际运行；需要验证重登时等待自然认证失效，不把启动请求成功当作恢复成功。
4. 确认正常后，通过文件资源管理器处理旧目录。保留其中不属于本程序的文件；只删除确认不再使用的旧后台 EXE、任务脚本、`.env` 和相关日志。不要再次启动旧目录程序。

旧目录的三个程序/配置文件以及其他文件均保留。安装事务备份位于 `%LOCALAPPDATA%\AutoLogin_SIAS_Backups`，注册脚本的任务备份位于 `%LOCALAPPDATA%\AutoLogin_SIAS\TaskBackups`；它们可能含凭据或账户信息，不要上传。确认无需回退后，可手动清理确认属于本项目的旧备份。

## 暂停、恢复和卸载

本版没有自动卸载按钮或专用卸载命令。以下是手动操作，会停止自动恢复网络；请先确认当前任务和目录。

### 暂停及恢复

1. 按 `Win + R` 输入 `taskschd.msc`，在“任务计划程序库”找到 `AutoLogin_SIAS`。权限不足时以当前账户管理员权限打开。
2. 右键“禁用”，阻止后续触发；若显示“正在运行”，再右键“结束”。仅禁用不会停止当前运行。
3. 打开任务管理器“详细信息”，显示“用户名”和“映像路径名称”，核对当前账户、任务 EXE 的完整路径。如果仍有该目录的后台进程，逐一结束这些已确认实例。不能只按文件名结束其他目录的同名程序。
4. 暂停期间不再自动维护。恢复时在任务计划程序右键“启用”；连接 UESTC 后按需“运行”，夜间模式在窗口外仍会正常退出。

结束任务可能留下冻结 EXE 的子进程，所以删除文件前必须核对残留。无法确认进程归属或文件仍被占用时，先[收集状态反馈](TROUBLESHOOTING.md#反馈问题)，不要强行删除。

### 卸载

1. 按上面步骤禁用、结束并确认没有属于本安装目录的后台进程；先按需私下保存配置或日志。
2. 在任务“属性 → 操作”再次核对路径，关闭属性窗口后右键删除 `AutoLogin_SIAS`。其他任务不属于本次卸载。
3. 在文件资源管理器删除该安装目录中属于本项目的文件。目录还存有其他资料时，只删除已确认的程序、配置和日志，不删除整个目录。
4. 按需清理迁移留下的其他安装副本、本项目备份和下载的安装器。备份也可能保存旧密码，应作为敏感文件处理。

完成后任务列表不再有本任务，已确认安装路径没有后台实例。卸载不会主动注销校园网，也不会删除其他网络配置。

## 配置与隐私

`.env` 保存账号密码，JSON 字符串编码不是加密。保留原格式标记，不建议手工编辑。需要改凭据时使用完整安装器。

普通后台运行为兼容旧部署，优先读取非空 `WLAN_USER`、`WLAN_PWD` 环境变量，再读取配置文件；配置查找依次为程序目录、父目录、当前工作目录。安装器强制验证的是本次保存配置，不使用旧环境变量替代。如果以前配置过这些环境变量，安装验证成功不能证明后台实际使用了同一密码，见[凭据验证失败](TROUBLESHOOTING.md#凭据验证失败或配置冲突)。

门户使用 HTTP 和 RC4 兼容协议，不能视为现代加密传输。仅使用自己的账户和有权访问的网络。不要公开 `.env`、凭据备份、账号密码、Cookie、认证令牌、真实 MAC 地址或原始抓包；反馈前检查日志片段并脱敏。
