## 独立实验

[实验工具索引](../../tools/experiments/README.md)包含循环监测、单次诊断和资源测量。它们不随正式安装部署，不自动修改任务；运行可能额外查询或提交认证，实验监测还会阻止自动睡眠。请按工具说明隔离实验，结束后恢复自行暂停的正式维护。

实验结果、真实日志和凭据保存在本机，不提交公开仓库。不同构建、检测周期和同时运行的维护程序可能改变观察，不能直接合并成每晚规律。历史测量保留范围和局限，不推广为所有设备的性能承诺。
