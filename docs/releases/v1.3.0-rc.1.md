# v1.3.0-rc.1

本版为预发布候选，增加正式程序的认证状态检测；v1.2.0 仍是稳定版。尚未完成新版正式 EXE 的真实校园网验证，不以一晚实验结果推断每日固定失效时刻。

- 单次运行先查询 `/homepage/info.php`。已认证记录状态并跳过登录，需认证时使用原认证协议。
- 状态检测未知时记录原因并尝试原认证流程，避免临时查询失败阻断恢复。
- 登录响应成功后再次确认门户认证状态；未认证或未知返回已有退出码 8，不误报恢复。
- 日志保存前后状态、动作、登录响应判断、确认结果、退出码和耗时，不记录个人资料或凭据。
- Wi-Fi 事件、04:10 默认计划、现有任务条件、安装和更新方式均保留。
- 独立夜间实验及单次诊断的源码、测试、说明和构建脚本放在 `tools/experiments/`，不包含真实记录，不随安装器部署。

资产：`AutoLogin_SIAS_Installer.exe`、`AutoLogin_SIAS_Headless.exe`、`SHA256SUMS.txt`。已有用户若只想测试候选版，可以放在独立目录并使用已有配置手动 `--check`；不要同时运行多个监测器。确认门户认证不代表外网一定可用；已在线跳过不表示此次验证了配置中账号密码。

自动验证包括正式源码测试、实验工具测试、任务 XML 预览、安装包内容校验、真实打包 EXE 的本机模拟门户测试和模拟安装回滚。仍待新版校园网、UAC、锁屏及重连实机验证。实验使用同一构建版本连续运行，保留本地构建信息和参数。
