# v1.3.0-rc.2 两种维护模式

这是候选版本；稳定版下载仍为 v1.2.0。维护模式需要 Windows Wi-Fi 接口和 UESTC 网络；电脑睡眠期间不能检测。本版不新增唤醒或防休眠策略。

## 安装和升级

运行本版 AutoLogin_SIAS_Installer.exe，使用同一 Windows 账户允许 UAC 提权。选择绝对安装路径（默认 `%LOCALAPPDATA%\AutoLogin_SIAS`），然后选择模式：

| 模式 | 行为 |
|---|---|
| ① UESTC 持续维护 | 连接 UESTC 后每30秒检测，确认离开后退出；重连重新启动 |
| ② 夜间时段维护（默认） | 每天02:55～03:15，每5秒间隔检测；窗口外直接退出，恢复后继续检测到窗口结束 |

默认使用电脑本地时间。两种模式均只在确认连接 UESTC、门户明确要求认证时尝试登录，失败后至少等待15秒再试；请求耗时会延长检测间隔。未知状态不会触发登录。

有旧配置时可以保留账号密码，否则输入自己的校园网凭据。安装器验证凭据后更新 AutoLogin_SIAS 任务，并启动它；夜间模式白天启动会正常退出。升级会显式替换旧 WLAN/时间触发器，旧04:10时间不再保留。账户和电源条件保留，执行时限按模式调整；连接、开机和用户登录触发用于补启动。无法识别的任务动作或触发器会拒绝自动迁移。

旧安装位置取自 AutoLogin_SIAS 任务，不扫描其他目录。文件先备份到 `%LOCALAPPDATA%\AutoLogin_SIAS_Backups`，旧任务 XML 保存在新安装目录所属账户的 TaskBackups 中。迁移成功后只删除旧安装目录中的后台EXE、任务脚本和.env，且删除前核对内容未变化；日志、实验程序及其他文件保留。旧EXE父目录的共享.env不会被清理。同目录升级先备份再替换。

安装验证失败会恢复本次替换的文件；任务注册开始后若失败则保留新文件和备份，以免已更新的任务引用缺失文件。根据错误修复后重新运行安装器，或使用任务XML和文件备份回退。

## 日常检查和停用

在任务计划程序检查 AutoLogin_SIAS 的操作参数是 `--maintain night` 或 `--maintain continuous`。查看所选目录的 auto_login_headless.log：包含模式、状态变化、登录结果和退出原因；日志轮转，长期在线时不逐次打印。

停用时先结束运行中的任务，再禁用任务；只禁用触发器不会停止已运行的持续维护进程。切换模式或更改安装位置重新运行安装器。不要同时运行两份正式维护程序；程序有单实例控制，独立夜间实验仍单独保留，但同时运行会竞争重登，实验时应结束并禁用正式任务。

夜间模式的验收方法见 [维护与验证](../DEVELOPMENT.md)。仍为预发布；持续模式长期运行、睡眠恢复、真实重连及完整新装向导需按使用环境验收。

## 安装迁移排障

如果旧任务包含已过期的一次性 TimeTrigger，安装器会拒绝自动迁移。先导出完整任务XML；确认时间已过期且没有重复计划后，在任务计划程序中仅删除该旧触发器，再继续安装。不要直接删除仍有效的自定义触发器。

若EXE路径存在但任务启动返回0x80070002，检查所选目录是否加密、执行账户是否可访问。安装位置可选择其他能被该账户读取的未加密目录。保留原目录加密设置，使用备份恢复和重新迁移。
