# v1.3.0-rc.3 候选版

> 历史候选说明：正文描述当时状态，不是当前安装指南。正式版见[v1.3.0](v1.3.0.md)，验收结论见[最终记录](v1.3.0-acceptance.md)。

安装流程和两种模式见 [rc.2 操作指南](v1.3.0-rc.2.md)。本版增加安装失败时的完整文件/任务恢复；任务设置在禁用前备份，保留原启用状态，仅重启原先运行的任务。

任务注册开始后的失败不再仅保留新文件：维护安装会先停止任务，恢复原文件和原任务 XML；首次安装失败删除本次任务。恢复不成功时明确报错并保留备份，需人工检查，不会显示部署成功。

正式发布前按 [实机验收清单](../history/v1.3.0-acceptance-checklist.md) 提交固定结果。自动化通过不等于实机验收完成。实验工具不进入正式安装包，原始日志和凭据不上传。

安装前检查目录是否启用 EFS 加密，若启用则拒绝安装并提示选择未加密目录；检查发生在停止旧任务前。
