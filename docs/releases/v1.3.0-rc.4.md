# v1.3.0-rc.4 候选版

安装和两种模式见 [rc.2 操作指南](v1.3.0-rc.2.md)，安装失败恢复及 EFS 检查沿用 [rc.3](v1.3.0-rc.3.md)。本版修复响应误判、维护策略和验收日志归属，增加安装器互斥；旧候选的验证结果不替代本轮验收。

- 结构化结果优先，失败/否定文字拒绝；含糊、冲突、重复字段无法确认。即使安装前在线，被拒绝的凭据验证也不会成功。
- 维护模式仅在最新状态明确需认证时登录；未知等待，已认证跳过。旧单次未知回退与强制验证分别保留。
- 网络检测完成后和实际提交凭据前重新检查窗口与 Wi-Fi。窗口外不发起新认证，窗口内已发出的认证允许完成后续跳转和状态确认。默认循环间隔5秒/30秒，请求耗时另计。
- 运行编号、带时区时间和提交/确认结果写入结构化日志。状态采集使用 JSON v2，按当前任务轮次提取，支持轮转；找不到本轮记录、异常或重复启动返回无法确认。
- 安装器开始读取旧状态前持有跨进程锁，安装和恢复期间第二实例明确退出。

按 [固定验收步骤及回复模板](../RELEASE-ACCEPTANCE.md) 实测。正式版尚未发布；凭据和原始日志不提交仓库。
