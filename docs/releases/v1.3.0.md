# v1.3.0 正式版说明

v1.3.0 已正式发布，适合在 UESTC 使用 SIAS 认证的 Windows x64 用户。本文保留版本变化和验证边界，操作说明集中在当前指南，避免重复维护。

[正式下载](https://github.com/LeeAstra/autologin-sias/releases/tag/v1.3.0) · [安装与使用](../USAGE.md) · [故障排查](../TROUBLESHOOTING.md) · [最终验收](v1.3.0-acceptance.md) · [来源与 SHA256](../MAINTENANCE.md#v130-来源与验证)

## 本版变化

- 保持认证核心、通用循环、Windows 平台三层结构。Windows Wi-Fi 检测使用 WLAN API，避免每轮启动 netsh。
- 完整安装器提供“① UESTC 持续维护”和默认“② 夜间时段维护”，可选择目录。模式参数、间隔和运行条件见[首页比较](../../README.md#选择哪种模式)。
- 先检测再认证，维护期间未知不提交；提交前再次确认 UESTC 和夜间窗口。响应成功及恢复状态严格判定，未实际提交不增加 15 秒冷却。
- 安装器及独立源码 `--setup` 验证本次保存的凭据，忽略旧环境变量覆盖；已在线也强制验证。
- 旧任务先只读预检，不支持时在停止和替换前退出。保留安装互斥、文件/任务备份及失败恢复，安全处理同账户同路径冻结残留进程。
- 迁移保留旧目录文件，明确说明启动请求不等于运行成功；持续模式验收采集支持没有下次定时运行时间。

## 升级影响

使用完整安装器升级会更新程序、保存配置、计划任务执行路径和所选模式的触发器/时限；保留旧任务电源条件。仅替换后台 EXE 不会切换模式。旧文件处理及恢复方式见[使用指南](../USAGE.md#升级切换模式或更换凭据)。

## 已验证和限制

完整 Linux/Windows CI、生产冻结 EXE、两种模式隔离安装/升级/迁移与失败恢复验证通过。本机另验证原位升级、迁移运行、断网重连、睡眠恢复和 2026-10-08 自然登出重登。当天从检测需要认证到确认恢复约 0.539 秒；不包含未知的实际登出至检测时间，也不能作为日常恢复承诺。

本轮没有实机覆盖其他 Wi-Fi、多无线网卡、全新账户、锁屏和 WLAN 服务故障。迁移旧文件保留有自动测试，但实机没有迁移时目录快照。单晚观察到一次登出不能推出每晚规律。

安装包未签名，不自动唤醒或连接 Wi-Fi，普通后台仍兼容环境变量优先；其他协议或系统需独立验证。

## 安装行为防护兼容性

火绒对安装器调用 PowerShell 注册脚本的用户反馈为“已允许”；后续任务和实际运行已核验，不代表所有策略都兼容。用途、参数范围和遇到拦截时的核查步骤统一见[行为防护说明](../TROUBLESHOOTING.md#火绒或其他行为防护提示)。不关闭防护、全目录加白或盲目删除参数；原生任务接口替换留作后续评估。
