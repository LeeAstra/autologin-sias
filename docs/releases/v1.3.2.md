# v1.3.2 发布说明

v1.3.2 修复夜间模式在白天由 UESTC Wi-Fi 连接事件启动时，识别到 `auth_required` 却未提交登录的问题。

- 首次连接检查允许在夜间窗口外登录。
- 已认证跳过，未知状态不提交凭据。
- 首次检查后的夜间维护仍限于 02:55～03:15、每 5 秒一次。
- v1.3.2 通过源码回归、Windows 构建和冻结包检查；实机网络覆盖以既有验收记录为准。
